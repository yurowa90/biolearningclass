# 과학 증거 탐구 작업실

과학 자료를 관찰하고 질문을 만들며, 고른 근거를 바탕으로 주장·근거·추론(CER) 설명을 완성하는 학생용 탐구 웹앱입니다.

- 바로 쓰기: **https://science-evidence-lab.yurosung.chatgpt.site**

## 누구를 위한 도구인가

2022 개정 교육과정 과학 과목을 배우는 학생이 쓰는 화면입니다. 현재 공개된 화면은 학생용 하나입니다.

## 무엇을 하나

학생은 다음 순서로 탐구합니다.

1. 자료 읽기
2. 관찰 기록
3. 탐구 질문 작성
4. 설명에 사용할 근거 선택
5. 주장·근거·추론(CER) 작성
6. 결과 검토 및 저장

- 자료는 단계에 따라 차례로 공개됩니다.
- 증거 카드마다 관련 성취기준이 연결되어 있습니다.
- 데스크톱·태블릿·휴대폰 화면에 맞춰 보입니다.

다루는 과목은 통합과학1·2, 과학탐구실험1·2, 생명과학, 세포와 물질대사, 생물의 유전입니다. 이 7과목의 성취기준 97개가 들어 있습니다.

## 사용 방법

위 주소를 브라우저에서 열면 바로 탐구를 시작할 수 있습니다. 로그인이나 API 키는 필요 없습니다.

작성한 내용은 그 브라우저 세션에만 임시로 저장됩니다. 탭이나 브라우저를 닫으면 사라질 수 있으니 필요한 내용은 따로 옮겨 두세요.

## 내 컴퓨터에서 실행하기

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

## 한계

- 학급 제출, 계정, 데이터베이스, 교사 대시보드는 아직 연결하지 않았습니다. 교사가 학생 작성 내용을 모아 볼 수 없습니다.
- 저장은 브라우저 세션 임시 저장뿐입니다.
