# 과학 증거 탐구 작업실

과학 자료를 관찰하고 질문을 만들며, 선택한 근거를 바탕으로 CER 설명을 완성하는 학생용 탐구 웹앱입니다.

## 학생 탐구 흐름

1. 자료 읽기
2. 관찰 기록
3. 탐구 질문 작성
4. 설명에 사용할 근거 선택
5. 주장·근거·추론(CER) 작성
6. 결과 검토 및 저장

## 교육과정 범위

- 통합과학1·2
- 과학탐구실험1·2
- 생명과학
- 세포와 물질대사
- 생물의 유전
- 2022 개정 교육과정 7과목, 97개 성취기준 데이터 포함

## 현재 구현

- 단계형 자료 공개와 학생 탐구 진행
- 증거 카드와 성취기준 연결
- 관찰·질문·근거·CER 작성
- 브라우저 세션 임시 저장
- 데스크톱·태블릿·모바일 반응형 화면
- 논술형 평가 웹앱과 동일한 디자인 토큰 적용

실제 학급 제출, 계정, 데이터베이스, 교사 대시보드는 아직 연결하지 않았습니다.
