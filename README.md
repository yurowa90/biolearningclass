# 과학 증거 탐구 작업실

과학 자료를 관찰하고 질문을 만들며, 선택한 근거를 바탕으로 CER 설명을 완성하는 학생용 탐구 웹앱입니다.

## 학생 탐구 흐름

1. 자료 읽기
2. 관찰 기록
3. 탐구 질문 작성
4. 설명에 사용할 근거 선택
5. 주장·근거·추론(CER) 작성
6. 결과 검토 및 저장

## 교육과정 범위

- 통합과학1·2
- 과학탐구실험1·2
- 생명과학
- 세포와 물질대사
- 생물의 유전
- 2022 개정 교육과정 7과목, 97개 성취기준 데이터 포함

## 현재 구현

- 단계형 자료 공개와 학생 탐구 진행
- 증거 카드와 성취기준 연결
- 관찰·질문·근거·CER 작성
- 브라우저 세션 임시 저장
- 데스크톱·태블릿·모바일 반응형 화면
- 논술형 평가 웹앱과 동일한 디자인 토큰 적용

실제 학급 제출, 계정, 데이터베이스, 교사 대시보드는 아직 연결하지 않았습니다.

## 켄텍 창의성 면접 연습실

`public/kentech-creativity/`는 한국에너지공과대학교(KENTECH) 2022~2026학년도 수시 창의성 면접 기출을 게임으로 재구성한 정적 웹앱입니다. 앱을 실행한 뒤 `/kentech-creativity/index.html`로 접속하거나, 폴더를 아무 정적 서버로 열면 됩니다.

| 학년도 | 게임 | 핵심 조작 |
|---|---|---|
| 2022 | 미션 켄텍 | 10×10 지도에 발전소를 배치하고 세 마을에 전선 연결 |
| 2023 | 가람국 10년 계획 | 실행 항목 경로를 따라 10년 계획, 이웃국 대비 경계·위험 판정 |
| 2024 | 켄트로늄 정착 시뮬레이터 | 헥스 지도와 특별 아이템으로 탐험 계획, 맞춤형 질문 생성 |
| 2025 | 켄테시아 타임스 | 신문 4부 발행 순서 추론과 인과 근거 작성 |
| 2026 | 최우수 혁신기술 선정평가 | 홍보자료 4종 비판적 분석, 평가표 채점과 추천 |

- 각 게임은 준비실(타이머·자료 조작) → 면접실(후속 질문) → 성찰(공식 평가 기준 자기 평가, 출제 의도, 예시 답안 비교) 순서로 진행합니다.
- 문항과 자료는 각 학년도 선행학습 영향평가 보고서에서 옮겼습니다. 2024학년도 시뮬레이션 계산식처럼 공개되지 않은 부분은 새로 설계했고 화면에 '재구성'으로 표시했습니다.
- 입력 내용은 브라우저 `localStorage`에만 저장됩니다.
